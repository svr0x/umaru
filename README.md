## About

Umaru is a verified, all-in-one Discord bot developed solo and trusted by 245+ servers and 65,000+ users, with 84 prefix commands and 47 slash commands. It started as a partnership and moderation bot and has grown into a full toolkit for running a server.

> **Note:** This repository is a landing page only. The bot's source code is private.

## Features

- **Moderation** — ban, kick, timeout, warn, lock/unlock, and more, with clean DM notifications
- **Anti-Nuke and Anti-Raid** — detects mass bans/kicks, channel and permission tampering, webhook abuse, emoji/sticker deletion, and automatically punishes and reverts
- **Logging** — webhook logging for 30+ server events
- **Backup and Restore** — save your server structure and restore it with a confirmation flow
- **Economy and Games** — currency, gambling, and leaderboards
- **Partnership Management** — tools for handling server partnerships
- **Utility** — social lookups and handy everyday commands
- **Modern UI** — built with Discord's Components V2 for clean, readable menus

## Getting Started

1. [Invite Umaru](https://top.gg/bot/1490160677468241981) to your server.
2. Use the `-` prefix, for example `-help`, to open the help menu. Slash commands work too.
3. Need a hand? Join the [support server](https://discord.gg/KEC8Ddav4g).
