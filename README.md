## About

Umaru is a verified, all-in-one Discord bot developed solo and trusted by 245+ servers and 65,000+ users, with 84 prefix commands and 47 slash commands. It started as a partnership and moderation bot and has grown into a full toolkit for running and protecting a server.

> **Note:** This repository is a landing page only. The bot's source code is private.

## Features

### Partnership System
- Partnership tracker with a manager points leaderboard
- Set your server ad and partner role, with logs for every new partnership
- Alerts when a partner leaves, so old ads can be cleaned up
- Custom thank-you message for new affiliates

### Moderation
- Ban, unban, kick, timeout, softban, warn, and jail
- Purge, lock/unlock, sticky messages, and snipe
- Automod: anti-link, anti-spam, and bad word filter
- Clean DM notifications for punished members

### Anti-Nuke and Security
- Detects and reverts channel, role, webhook, and server setting changes
- Mass ban/kick protection, bot add protection, and vanity URL protection
- Whitelist system for trusted users
- Honeypot channel that catches hacked accounts and spam bots

### Backup and Restore
- Back up your roles, categories, channels, permissions, and emojis
- Restore with a confirmation flow and live progress
- Auto backup, backup history, and backup comparison
- Free and premium tiers

### Community Tools
- Welcome and leave messages with custom embeds, plus welcome DMs
- Autoresponder (slash commands)
- Reaction roles, autoreact, and vanity roles from status keywords
- Counting channel
- Auto role and bulk role tools

### Logging
- Webhook logs for 30+ server events
- Mod log and automod log channels

### Utility
- User, server, and role info
- Avatar, banner, server profile, and server banner viewers
- AFK system, member count, emoji/sticker steal, and more
